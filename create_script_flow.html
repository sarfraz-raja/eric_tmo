7. Parameter ka asar

InputKya decide karta hai
Site IDSirf folder/log/zip ka naam. Node list CIQ se aati hai.
Software ReleaseSW package, nodeIdentifier, Mo baseline, aur script ke release-wise blocks (jaise swname[:9] > 'TMO_25_Q3').
SubNetworkdnPrefix, NTP, timezone, MME/AMF pool, aur market-wise scripts.
ENMnodeIdentifier aur Client record. Galat combination par Client nahi milega aur request fail hogi.
CIQNodes, cells, IP, VLAN, RF, BBType, IDLE. Cell ka pehla letter (A, J, K, L…) band-wise logic chalata hai.
DCGKPurani config: BBChange, presite, movement, fingerprint, purane radio. Ye optional field hai.

8. Failure aur dhyan rakhne wali baatein

Module fail hua: except me traceback log hota hai, status Failed, aur baaki modules ruk jaate hain. Jo files ban chuki thi, wo log ke saath zip ho jaati hain (tmobile_jobs.py:43-54).

Lambe job: pura kaam web request ke andar chalta hai. Is run me lagbhag 1 min 39 sec laga, itni der browser wait karta hai.

Password: NodeInfo.xml me node ka username/password likha jata hai, jo tmo_data.py:2-3 me hardcoded hai. Zip share karte waqt dhyan rakhein.
