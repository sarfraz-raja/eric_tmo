Create Script: backend flow

From the button click to the finished zip, and which file is generated under which condition. Example run: IE04692B_20261030005723

Note first: the log in this folder shows Riverside / PON05CNM / TMO_26_Q2_EC2, while the screenshot has Albuquerque / PON03CNM / TMO_25_Q3_EC2 selected. The examples in this document come from the Riverside run. Changing the market or release can change which files are generated and what they contain.

1. Which API is it?

Just one endpoint: POST /T-Mobile/script/. It is not a JSON API but a regular Django form submit. A GET on the same URL renders the form.

Route: mScripter/urls.py:10 → tmobile/urls.py:6 → script_tmobile() in tmobile/views.py:23

Form fields: swrel, mname, sw_enm, siteid, ciqfile, software_log (DCGK zip)

7. Effect of each parameter

InputWhat it decides
Site IDOnly the folder/log/zip name. The node list comes from the CIQ.
Software ReleaseSW package, nodeIdentifier, Mo baseline, and release-specific blocks in scripts (e.g. swname[:9] > 'TMO_25_Q3').
SubNetworkdnPrefix, NTP, timezone, MME/AMF pool, and market-specific scripts.
ENMnodeIdentifier and the Client record. A wrong combination finds no Client and the request fails.
CIQNodes, cells, IP, VLAN, RF, BBType, IDLE. The first letter of the cell (A, J, K, L…) drives the band-specific logic.
DCGKExisting config: BBChange, presite, movement, fingerprint, old radios. This field is optional.

8. Failures and things to watch

Module failure: the except block logs the traceback, status becomes Failed, and the remaining modules stop. Files already written are zipped together with the log (tmobile_jobs.py:43-54).

Long jobs: all the work runs inside the web request. This run took about 1 min 39 sec, and the browser waits that whole time.

Password: NodeInfo.xml contains the node username/password, which is hardcoded in tmo_data.py:2-3. Be careful when sharing the zip.
